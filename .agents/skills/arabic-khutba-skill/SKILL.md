# مهارة الخطبة المنبرية

> مبنية على أربعة مصادر:
> **«فن الخطابة»** لحسين بن محمد آل شامر (صنعة الإعداد والإلقاء)،
> **«الخطابة الإسلامية»** لعبد العاطي محمد شلبي (البناء والوعظ ونماذج الخطب)،
> **«خطبة الجمعة في الكتاب والسنة»** لعبد الرحمن بن محمد الحمد (فقه الخطبة وأدلتها)،
> **«الفقه على المذاهب الأربعة»** لعبد الرحمن الجزيري (تحرير الخلاف بين المذاهب).
>
> ومسنودة بـ**`arabic-writing-skill`** في اللغة ونبذ العَرَنْجِيَّة، وبـ**`arabic-tarjama-skill`** إن احتاجت الخطبة نقلاً من لغة أخرى.

> **تنبيه لا يُتجاوز:** هذه المهارة **لصناعة الخطبة وتحريرها، لا للفتوى**. تعرض أقوال المذاهب كما في مصادرها، والفتوى للجهة التي يتبعها المستخدم أو لعالمه. ولا يُنسب إلى الله تعالى أو إلى رسوله ﷺ إلا ما ثبت بدليل، ولا يُختلق نصّ ولا نسبة.

## ٠. قبل أن تكتب حرفاً: خمسة أسئلة

لا تبدأ الخطبة قبل أن تسأل. الأسئلة ليست إجراءً شكلياً؛ كل واحد منها يغيّر النص:

| السؤال | لماذا؟ | إن لم يُجب |
| :--- | :--- | :--- |
| **١. ما مذهبك أو مذهب المسجد؟** (حنفي / مالكي / شافعي / حنبلي / عام / لا تفضيل) | لأن أركان الخطبة وشروطها واللغة تختلف بين المذاهب | اكتب خطبة «عامة» على **التقاطع الاحتياطي** (الباب ٦)، ونبّه أن الفتوى للجهة المختصة |
| **٢. ما المناسبة؟** (جمعة / عيد / استسقاء / مناسبة أخرى) | لكل مناسبة عقدها وخطبتها | افترض الجمعة، واسأل قبل التسليم |
| **٣. من الجمهور؟** (عام / شباب / متخصصون / جالية / مختلط) | يحدد المستوى والطول والأمثلة | افترض جمهوراً عاماً متوسط الثقافة |
| **٤. ما الموضوع؟ وما الرسالة الواحدة؟** | الخطبة التي تحمل عشر رسائل لا تحمل رسالة | اسأل، ولا تختر عشوائياً |
| **٥. هل تسمح بإضافة أبيات شعرية؟** | لا يُقحم الشعر بلا إذن، ولا يُنسب بلا تحقق | لا تضف شعراً حتى يأذن |

**وأسئلة تكميلية عند الحاجة:**
- هل هناك مرجعية مفضلة؟ (الأزهر، دار الإفتاء، ابن باز، ابن عثيمين، كتب معينة…)
- هل هناك حساسيات محلية؟ (شخصيات، أحزاب، طوائف، قضايا سياسية)
- ما مدة الخطبة المطلوبة؟ (١٥ / ٢٠ / ٢٥ دقيقة)
- هل تريد نصاً كاملاً، أم مخططاً، أم مراجعة؟

> **إذا رفض المستخدم تحديد المذهب:** لا تخلط الأقوال ولا تفتِ. اكتب على التقاطع الاحتياطي، وقل في مقدمة تقريرك: «افترضتُ مذهباً عاماً؛ راجع التفاصيل الفقهية مع عالمك».

## ١. المبادئ العشرة

1. **الخطبة عبادة وتبليغ**، لا استعراض فصاحة ولا منصة سياسية.
2. **الجمهور ركن**؛ فالخطبة «فن مشافهة الجمهور» كما في «فن الخطابة»، وليست مقالاً يُقرأ.
3. **رسالة واحدة** لكل خطبة؛ ما زاد عليها تفسّخ.
4. **المذهب أمانة:** لا تخلط أقوال المذاهب في نصّ واحد بصيغة الجزم.
5. **المرجعية أمانة:** لا آية بلا سورة وآية، ولا حديث بلا مصدر ورقم وحكم، ولا قول بلا كتاب وصفحة.
6. **الرحمة قبل الترهيب:** الخطيب «يجمع ولا يفرّق، يصلح ولا يفسد، يؤلّف ولا ينفّر».
7. **التوازن:** لا تهويل ولا تهوين، ولا تجعل الخطبة سلسلة منكرات.
8. **الوقت أمانة:** ١٥–٢٠ دقيقة في الأحوال العادية، والأولى أطول من الثانية.
9. **اللغة أداة:** فصحى مبسطة، لا غريب ولا عامية متكلفة، ولا عرنجية.
10. **المنبر ليس محكمة:** لا تجريح، ولا أسماء في وقائع مشينة، ولا تكفير، ولا تحريض.

## ٢. بطاقة الخطبة (Intake Card)

قبل الكتابة، املأ هذه البطاقة. إن لم تتوفر معلومة، ضع `[تحتاج تحديداً]` واسأل:

```
المناسبة:            ...
المذهب/الجهة:        ...
الجمهور:             ...
المدة:               ...
الموضوع:             ...
الرسالة الواحدة:      ...
المحور القرآني:       ...
المحور الحديثي:       ...
القصة/المثال:         ...
التطبيق العملي:       ...
الدعاء الختامي:       ...
الشعر:               (مسموح / ممنوع / بشرط)
الحساسيات:           ...
```

**معيار الرسالة الواحدة:** أكمل هذه الجملة: «أريد أن يخرج المصلّي من الخطبة وهو عارفاً بـ...، وعازماً على...». إذا لم تستطع إكمالها بجملة واحدة، فالموضوع ما زال واسعاً.

## ٣. تشخيص الموضوع قبل الكتابة

### ٣.١ هل يصلح للخطبة؟

| السؤال | إن كان الجواب «لا» |
| :--- | :--- |
| هل هو موضوع واحد يمكن أن يخرج منه المصلّي بعمل؟ | ضيّقه أو اختر جزءاً منه |
| هل مادته الشرعية كافية (آية/حديث/أثر)؟ | ابحث عن دليل، أو غيّر الموضوع |
| هل يخاطب حاجة الجمهور فعلاً؟ | اسأل عن همومهم |
| هل يصلح لمنبر عام لا لندوة متخصصة؟ | بسّط أو غيّر الزاوية |
| هل يورّطك في خلاف طائفي أو سياسي؟ | أجّله أو اطلب إذناً صريحاً |

### ٣.٢ مصادر الموضوع

1. **حاجة الجمهور** (سؤال الناس، همومهم، أخطاؤهم الشائعة).
2. **المناسبة** (رمضان، الحج، بداية العام، أزمة عامة).
3. **القرآن** (سورة أو آية محورية).
4. **السنة** (حديث صحيح يناسب المقام).
5. **الواقع** (ظاهرة أسرية أو اجتماعية، بلا تجريح).

### ٣.٣ فحص الموضوع بعشرة أسئلة

- [ ] هل الموضوع واضح في جملة واحدة؟
- [ ] هل له أصل في القرآن أو السنة؟
- [ ] هل يعالج حاجة حقيقية للجمهور؟
- [ ] هل يمكن تطبيقه عملياً هذا الأسبوع؟
- [ ] هل يتسع لخطبتين بلا حشو؟
- [ ] هل فيه خطر طائفي أو سياسي؟
- [ ] هل يمكن تأديته بلا أسماء أشخاص؟
- [ ] هل توجد فيه مادة موثوقة كافية؟
- [ ] هل يناسب مستوى الجمهور؟
- [ ] هل ينتهي برجاء وتبشير، لا بقنوط؟

## ٤. عقد الخطبة: البناء الكامل

### ٤.١ الخطبة الأولى

| الجزء | الوظيفة | الوقت التقريبي |
| :--- | :--- | :--- |
| **الافتتاح** | حمد الله والثناء عليه والشهادتان والصلاة على النبي ﷺ | ١–٢ دقيقة |
| **التمهيد** | مشكلة أو سؤال يشدّ الجمهور إلى الموضوع | ١–٢ دقيقة |
| **التأصيل** | آية أو حديث محوري، بشرح موجز | ٣–٤ دقائق |
| **النقطة الأولى** | فكرة واحدة بدليلها ومثالها | ٣–٤ دقائق |
| **النقطة الثانية** | فكرة ثانية بدليلها ومثالها | ٣–٤ دقائق |
| **التطبيق** | ماذا يفعل المصلّي؟ | ١–٢ دقيقة |
| **الخاتمة الأولى** | تلخيص + دعاء + تمهيد للثانية | ١ دقيقة |

### ٤.٢ الجلوس

- اجلس بين الخطبتين بقدر سورة الإخلاص أو ثلاث آيات، كما في سنة أكثر المذاهب.
- لا تتكلم في الجلوس بغير ذكر أو دعاء.
- الجلوس عند الشافعية **شرط** بقدر الطمأنينة؛ وعند الجمهور سنة. فاجعله فاصلاً واضحاً.

### ٤.٣ الخطبة الثانية

| الجزء | الوظيفة |
| :--- | :--- |
| **الافتتاح** | حمد الله والصلاة على النبي ﷺ |
| **الاستكمال** | تتمة الموضوع، أو علاج مشكلة، أو فائدة جديدة |
| **الدعاء للمؤمنين** | دعاء جامع، وفي الثانية خاصة عند الشافعية |
| **الدعاء الخاص** | لولي الأمر والمسلمين، بصيغة عامة وبلا تجريح |
| **الخاتمة** | استغفار + صلاة على النبي + دعاء موجز |

### ٤.٤ الافتتاحيات الأربع

| النوع | مثاله | متى يصلح |
| :--- | :--- | :--- |
| **الإشارة إلى الموضوع** | «بين يديكم اليوم حديثٌ عن أمانة الكلمة...» | عندما يكون الموضوع واضحاً |
| **حكمة أو آية أو حديث** | «قال الله تعالى: ﴿وَقُولُوا لِلنَّاسِ حُسْنًا﴾ — البقرة: ٨٣» | عندما يكون النص محورياً |
| **سؤال أو مفارقة** | «ما الذي يجعل بيتاً صغيراً يسع السعادة، وبيتاً كبيراً لا يسعها؟» | لجذب الانتباه |
| **قصة قصيرة** | قصة واقعية موجزة (بلا أسماء) | عندما تخدم الفكرة |

**محاذير الافتتاح:** لا تطل أكثر من خمس دقائق، ولا تبدأ باعتذار طويل، ولا بموضوع لا علاقة له بالخطبة، ولا بسجع متكلف.

### ٤.٥ العرض: ثلاث حركات

1. **التشخيص:** ما المشكلة؟ ما صورتها في الواقع؟ (بلا تجسيد مخل).
2. **التأصيل:** ما حكمها/قيمتها في القرآن والسنة؟ (بدليل موثق).
3. **التطبيق:** ما الخطوة العملية؟ (واحدة أو اثنتان، لا عشر).

### ٤.٦ الخاتمة

- **لخّص** الرسالة في جملتين.
- **ادعُ** دعاءً مرتبطاً بالموضوع.
- **بشّر** ولا تُقنط.
- **توقّف** عند الذروة؛ لا تُضف ذيلاً.

## ٥. الجمهور والمناسبة

### ٥.١ أنواع الجماهير

| النوع | المدخل المناسب |
| :--- | :--- |
| **المؤيد** | عزّز القيم، واشكر، وادفع للعمل |
| **المعارض** | ابدأ بقوة هادئة، واحذر الكلمات المستفزة |
| **المحايد** | أبدع وأقنع وأمتع، بلا مصطلحات |
| **غير المهتم** | ابدأ بقصة، ثم حقيقة، ثم تطبيق |
| **العامة** | لغة سهلة، أمثلة قريبة، بلا مصطلحات |
| **المتخصصون** | حجة، دليل، إحصاء، بلا تبسيط مخل |

### ٥.٢ مستوى اللغة

- **فصحى مبسطة** هي الأصل.
- اشرح المصطلح الغريب في جملة قصيرة.
- لا تستعمل العامية إلا لحكاية قول أو مثل، وبقدر.
- لا تستعمل الغريب («التِّبر»، «الأخول») للاستعراض.
- لا تستعمل العرنجية (`من خلال`، `على صعيد`، `بالنسبة لـ`، `قام بـ`).

### ٥.٣ الطول

- **١٥–٢٠ دقيقة** في الأحوال العادية؛ والأولى أطول من الثانية.
- راعِ المرضى وكبار السن والحرّ والبرد وأصحاب الحاجات.
- «كانت صلاته قصداً وخطبته قصداً» (مسلم ٨٦٦).
- «إن طول صلاة الرجل وقصر خطبته مئنة من فقهه» (مسلم ٨٦٩).

## ٦. الفقه: المذاهب الأربعة

> **اقرأ هذا الباب كله قبل الكتابة.** لا تخلط الأقوال، ولا تفتِ، ولا تُجزم في مسألة خلافية. والمرجع التفصيلي: `references/fiqh_madhahib.md`.

### ٦.١ جدول جامعة

| المسألة | الحنفي | المالكي | الشافعي | الحنبلي |
| :--- | :--- | :--- | :--- | :--- |
| **عدد الأركان** | واحد: مطلق الذكر | واحد: تحذير أو تبشير | خمسة | أربعة |
| **الحمد** | ليس ركناً | ليس ركناً | ركن (من مادة حمد + لفظ الجلالة) | ركن بلفظ «الحمد لله» |
| **الصلاة على النبي** | ليست ركناً | ليست ركناً | ركن بلفظ الصلاة | ركن بلفظ الصلاة |
| **الوصية بالتقوى** | ليست ركناً | ركن ضمن «التحذير/التبشير» | ركن | ركن |
| **الآية** | ليست ركناً | ليست ركناً | ركن في إحداهما | ركن في كلتيهما |
| **الدعاء للمؤمنين** | سنة | سنة | **ركن** في الثانية | سنة |
| **عدد الخطب** | خطبتان: إحداهما شرط والأخرى سنة | خطبتان (وقيل: واحدة) | خطبتان شرط | خطبتان |
| **الجلوس بينهما** | سنة | سنة | **شرط** بقدر الطمأنينة | سنة |
| **اللغة** | تصح بغير العربية مطلقاً | **العربية شرط** | العربية في الأركان بتفصيل | العربية للقادر، والآية لا تُنطق بغيرها |
| **القيام** | سنة | شرط (وقيل سنة) | شرط إن قدر | سنة |
| **الطهارة** | سنة | سنة | **شرط** | ليست في الشروط المذكورة |
| **عدد الحاضرين** | واحد ممن تنعقد بهم الجمعة | اثنا عشر | أربعون سامعون ولو بالقوة | العدد الذي تجب عليه الجمعة |
| **وقت الخطبة** | وقت الظهر | وقت الظهر | وقت الظهر يقيناً | وقت الظهر |

> **المصدر:** «الفقه على المذاهب الأربعة» للجزيري، كتاب الصلاة/الجمعة، و«خطبة الجمعة في الكتاب والسنة» للحمد. الأعداد والفروق كما وردت فيهما، مع تنبيه إلى تعارض نقلي في عدد خطب المالكية (خطبة واحدة عند الحمد نقلًا عن مالك، وخطبتان عند الجزيري).

### ٦.٢ كيف تستعمل الجدول؟

1. **اسأل عن المذهب** أولاً، ثم اكتب على أساسه.
2. **لا تخلط:** لا تجعل الحنفي شافعياً في الأركان، ولا المالكي حنبلياً في اللغة.
3. **لا تُفتِ:** قل «المعتمد عند السادة الشافعية كذا»، «وعند المالكية كذا»، «وفي المسألة خلاف»، «والفتوى لجهتكم».
4. **إذا كان المستخدم «عاماً»:** استعمل **التقاطع الاحتياطي** أدناه.
5. **إذا كان المسجد يتبع جهة معينة:** اتبعها، ولا تناقشها على المنبر.

**مراجع المذاهب للاستزادة** (ليست مصادر استُخرجت منها هذه المهارة، بل إحالات لمن أراد التفصيل):

| المذهب | من كتبه المعتمدة |
| :--- | :--- |
| **الحنفي** | «الهداية» للمرغيناني، «رد المحتار» لابن عابدين |
| **المالكي** | «الخرشي على مختصر خليل»، «حاشية الدسوقي» |
| **الشافعي** | «المجموع» للنووي، «تحفة المحتاج» لابن حجر الهيتمي |
| **الحنبلي** | «المغني» لابن قدامة، «كشاف القناع» للبهوتي |
| **عام/مقارن** | «الفقه على المذاهب الأربعة» للجزيري، «بداية المجتهد» لابن رشد |

### ٦.٣ التقاطع الاحتياطي (لمن لم يحدد مذهباً)

هذه صيغة تجمع أكبر قدر من الأركان عند الأربعة، **وليست فتوى**:

```
الخطبة الأولى:
١) الحمد لله بلفظ الحمد + الثناء + الشهادتان.
٢) الصلاة على النبي ﷺ بلفظ الصلاة.
٣) الوصية بالتقوى بلفظها أو بمعناها.
٤) آية تامة مفهومة (وعد/وعيد/حكم/قصة/مثل).
٥) تحذير أو تبشير صريح (لركن المالكي).
٦) دعاء للمؤمنين (اختياري في الأولى، واجب في الثانية عند الشافعي).
(يجلس)
الخطبة الثانية:
١) الحمد والصلاة.
٢) آية تامة (لركن الحنبلي).
٣) الوصية بالتقوى.
٤) الدعاء للمؤمنين والمؤمنات (ركن الشافعي في الثانية).
٥) خاتمة واستغفار.
```

**لماذا هذا التقاطع؟**
- يستوفي أركان الشافعي والحنبلي.
- ويستوفي ركن الحنفي (مطلق الذكر).
- ويستوفي ركن المالكي (التحذير/التبشير).
- ويجعل الخطبة بالعربية، وقبل الصلاة، وبصوت مسموع، وبجلوس بين الخطبتين.

**قيود:**
- لا تضمن به صحة الجمعة عند كل مذهب؛ فبعض الشروط (عدد الحاضرين، المكان، الطهارة) تختلف.
- لا تقدمه للناس على أنه «الحكم»؛ بل كصيغة عمل احتياطية، والفتوى للجهة المختصة.

---

## ٧. المرجعية: لا اختلاق، ولا نسبة بلا دليل

> **هذا هو الباب الأخطر في المهارة.** الخطبة الدينية لا تحتمل التخمين. والخطأ في آية أو حديث أو نسبة عالم أشد من الخطأ في الأسلوب.

### ٧.١ القاعدة الأم

> **لا يُكتب نصّ ديني إلا بعد التحقق. ولا يُنسب قول إلى الله أو رسوله ﷺ أو عالم إلا بمصدر يمكن الرجوع إليه.**

**ممنوع منعاً قاطعاً:**
- استخراج آية أو حديث من «ذاكرة» النموذج.
- اختراع رقم حديث أو صفحة كتاب.
- نسبة قول إلى عالم بلا مصدر.
- تحسين حديث ضعيف أو تصحيحه من غير أهل الفن.
- تحويل قول صحابي إلى حديث مرفوع.
- إكمال آية ناقصة من الذاكرة.
- نسبة بيت شعر إلى شاعر بلا ديوان.

### ٧.٢ بوابات التحقق الخمس

#### البوابة الأولى: القرآن

- أثبت النص كاملاً، ثم **اسم السورة ورقم الآية**.
- تحقق من الرسم من مصحف أو قاعدة موثوقة (Quran.com، Tanzil، مصحف المدينة).
- لا تختصر الآية اختصاراً يخلّ بالمعنى.
- إذا كان النص قراءة شاذة أو غير متواترة، فلا تنسبها إلى المصحف.

**مثال متحقق:**
> ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا إِذَا نُودِيَ لِلصَّلَاةِ مِن يَوْمِ الْجُمُعَةِ فَاسْعَوْا إِلَىٰ ذِكْرِ اللَّهِ وَذَرُوا الْبَيْعَ﴾ — الجمعة: ٩.

#### البوابة الثانية: الحديث

- أثبت **لفظ الحديث** كما في المصدر، أو اذكر أنه بالمعنى.
- اذكر **الكتاب والمصدر والرقم**.
- اذكر **حكم المحدث** (صحيح/حسن/ضعيف) كما قاله أهل العلم، لا من عندك.
- تحقق من التخريج في قاعدة موثوقة (الدرر السنية، Sunnah.com، الشاملة).
- إذا كان الحديث مشهوراً على الألسنة لكنه ضعيف، **لا تستعمله** أو اذكره بصفته الضعيفة إن كان في سياق تعليمي.

**أمثلة متحققة:**
| النص | المصدر | الحكم |
| :--- | :--- | :--- |
| «إن طول صلاة الرجل وقصر خطبته مئنة من فقهه...» | مسلم ٨٦٩ | صحيح |
| «كانت صلاته قصداً وخطبته قصداً» | مسلم ٨٦٦ | صحيح |
| «إذا قلت لصاحبك يوم الجمعة: أنصت، والإمام يخطب، فقد لغوت» | البخاري ٩٣٤، مسلم ٨٥١ | صحيح |

**مثال يجب الحذر منه:**
> «من تخطى رقاب الناس يوم الجمعة اتخذ جسراً إلى جهنم» — رواه الترمذي وابن ماجه وأحمد، وقال الترمذي: «غريب لا نعرفه إلا من حديث رشدين بن سعد». فهو **ضعيف**، لا يُقدّم على الحديث الصحيح في الباب. (ذكره الحمد في «خطبة الجمعة»، ونبّه على ضعفه.)

#### البوابة الثالثة: الأثر وقول العالم

- اذكر **القائل**، ثم **الكتاب**، ثم **الجزء والصفحة** إن أمكن.
- إن لم تجد الطبعة أو الصفحة، فاذكر الكتاب فقط إن كنت متحققاً من وجود القول فيه.
- لا تنسب إلى عالم قولاً سمعته في خطبة أو فيديو بلا تحقق.
- لا تجعل قول عالم حجة مستقلة؛ الحجة في الكتاب والسنة.

#### البوابة الرابعة: الشعر

- لا تُقحم الشعر بلا إذن المستخدم (الباب ٨).
- تحقق من **الشاعر** و**الديوان** و**البيت**.
- إن لم تتحقق من النسبة، فقل «يُنسب إلى...» أو احذفه.
- لا تجعل الشعر دليلاً شرعياً؛ هو شاهد أدبي.

#### البوابة الخامسة: الوقائع والتواريخ

- تحقق من الاسم والتاريخ والمكان.
- لا تذكر أرقاماً أو إحصاءات بلا مصدر.
- لا تبْنِ الخطبة على خبر صحفي لم تتحقق منه.
- في القصص المعاصرة، احذف الأسماء والتفاصيل التي قد تكشف الناس.

### ٧.٣ سجل المراجع (Reference Ledger)

اجعل في نهاية مسودتك جدولاً بهذا الشكل، ولا تسلّم خطبة بلا سجل:

| # | النص/الدعوى | النوع | المصدر | الرقم/الصفحة | الحكم | حالة التحقق | الإجراء |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| ١ | ﴿...﴾ | آية | الجمعة | ٩ | — | متحقق | أُبقي |
| ٢ | «...» | حديث | مسلم | ٨٦٩ | صحيح | متحقق | أُبقي |
| ٣ | «...» | حديث | الترمذي | ... | ضعيف | متحقق | حُذف |
| ٤ | بيت | شعر | ديوان ... | ... | — | لم يتحقق | حُذف/ينسب |

**حالات التحقق:**
- `متحقق`: روجع النص في مصدر موثوق.
- `يحتاج تحقيقاً`: لم يتيسر التحقق بعد؛ لا يُدرج في الخطبة.
- `لم يتحقق`: لا يُدرج.
- `محذوف`: حُذف لعدم التحقق أو للضعف.

### ٧.٤ قاعدة «اسأل قبل أن تنسب»

إذا لم تجد المصدر:
- لا تكتب: «قال النبي ﷺ...».
- اكتب في مسودتك: `[حديث يحتاج تخريجاً — لا يُدرج]`.
- اسأل المستخدم إن كان لديه مصدر أو نسخة من الكتاب.
- أو استبدل بالفكرة العامة بلا نسبة.

### ٧.٥ لا تُصحح ولا تُضعف بنفسك

- لا تقل «هذا حديث صحيح» إلا نقلًا عن محدث.
- لا تقل «إسناده حسن» إلا نقلًا.
- لا ترد على تصحيح أو تضعيف إلا بعلم.
- إن وجدت اضطراباً في التخريج، اذكره للمستخدم ولا تجزم.

### ٧.٦ وضع انقطاع التحقق

إذا لم تتوفر أدوات التحقق (إنترنت/مكتبة/نسخة من الكتاب):
- **لا تكتب نصاً دينياً من الذاكرة.**
- ضع فراغاً صريحاً: `[آية — تحتاج تحقيقاً]` أو `[حديث — يحتاج تخريجاً]`.
- اكتب الخطبة بلا النص غير المتحقق، أو استبدله بفكرة عامة.
- أبلغ المستخدم: «لم أتحقق من هذا النص؛ لا أدرجه حتى تراجعه».
- لا تملأ الفراغ لاحقاً بلا مصدر.

---

## ٨. الشعر: بوابة إذن وتحقق

### ٨.١ الإذن أولاً

في بطاقة الخطبة سؤال صريح: **«هل تسمح بإضافة أبيات شعرية؟»**
- إن قال **لا**: لا تضف بيتاً واحداً.
- إن قال **نعم**: يجوز، بشرط التحقق والاعتدال.
- إن قال **بشرط**: اسأل عن الشرط (شاعر معين، عصر، موضوع، عدد الأبيات).

### ٨.٢ قواعد الإقحام

1. **١–٣ أبيات** في الخطبة الواحدة، لا أكثر.
2. في **الافتتاح** أو **التطبيق** أو **الخاتمة**، لا في صلب الأدلة.
3. **لا يُستبدل** بالدليل الشرعي.
4. **لا يُنسب** إلى شاعر بلا ديوان.
5. **لا يُكسر** الوزن ولا يُحرّف اللفظ لأجل المعنى.
6. **لا يُستخدم** في الهجاء أو التجريح أو السياسة.
7. إن كان البيت مشهوراً بلا نسبة، قل «يُنسب إلى...» أو «من الشعر الذي يُتناقل».
8. **إذا وجدت بيتاً مناسباً أثناء البحث، فلا تدرجه مباشرة.** اعرضه على المستخدم في بطاقة: (البيت، الشاعر، الديوان، المصدر، حالة النسبة، الموضع المقترح)، واسأل: «هل تسمح بإضافته؟».

### ٨.٣ كيف تتحقق من بيت؟

- ابحث عن البيت في الديوان أو موسوعة شعرية موثوقة.
- تحقق من الشاعر والعصر والديوان.
- إن وجدت البيت في أكثر من مصدر بنسب مختلفة، اذكر الاختلاف أو احذفه.
- لا تعتمد على منشورات التواصل الاجتماعي.

---

## ٩. الحساسية: لا نُغضب أحداً

### ٩.١ المحرمات على المنبر

- **التكفير** أو التفسيق العام.
- **سبّ** المخالفين أو الطوائف أو الأديان.
- **ذكر أسماء** الأشخاص أو المؤسسات في وقائع مشينة.
- **التحريض** على العنف أو الفتنة.
- **التدخل** في السياسة الحزبية.
- **الطعن** في العلماء أو الجهات الشرعية.
- **الوصف الفجّ** للمعاصي والحدود.
- **السخرية** من الناس أو الجنسيات أو المهن.

### ٩.٢ القاعدة النبوية في النقد

> **القاعدة:** عمّم ولا تخصّ، وانقد الفعل لا الشخص؛ وهذا أسلوب نبوي في النقد، يُروى بصيغ متعددة في الصحيحين.

### ٩.٣ اسأل عن المحيط

- هل في المسجد جالية من مذهب آخر؟
- هل هناك قضية محلية حساسة؟
- هل هناك شخصيات لا يجوز ذكرها؟
- هل الخطبة تُبثّ؟ (تغيير الجمهور).

### ٩.٤ إذا كان الموضوع خلافياً

- اعرض الدليل والقول، ثم قل: «وفي المسألة خلاف بين أهل العلم».
- لا ترجّح أمام جمهور عام إلا إذا طلب المستخدم ذلك صراحةً وكان من أهل العلم.
- إذا كان الخلاف طائفياً، فالأفضل تركه أو معالجته بلا تسميات.

---

## ١٠. الإلقاء والمنبر

### ١٠.١ الصوت

- **الوضوح** قبل الجمال: بيّن الحروف والكلمات.
- **تنويع الطبقات:** لا صوت واحد رتيب.
- **الوقفة** عند نهاية الفكرة، وبعد السؤال، وقبل الدعاء.
- **السرعة** في المعروف (الصلاة على النبي، الثناء)، **والبطء** في الدليل والوعظ والدعاء.
- **الرفع** عند الترهيب والحث، **والخفض** عند الرقة والدعاء.
- **لا صراخ**؛ الصراخ يلغي الوقار.

### ١٠.٢ الجسد

- قف معتدلاً، صدرك للأمام، قدماك متوازنتان.
- لا تلتفت يميناً وشمالاً بلا حاجة.
- وزّع النظر على الصفوف، لا على الورقة.
- الإشارة القليلة أبلغ من الحركة الكثيرة.
- لا تعبث بالميكروفون أو المنبر.

### ١٠.٣ الورقة والحفظ

- **المبتدئ** يقرأ من ورقة منظمة، بخط كبير، وفواصل واضحة.
- **المتمكن** يلقي من عناصر، ولا يترك الورقة تماماً.
- **لا تحفظ** كل كلمة؛ احفظ الافتتاح والخاتمة والانتقالات.
- **تدرّب بصوت مسموع**، وسجّل نفسك، واسمعها.

### ١٠.٤ الميكروفون

- قف على المسافة الصحيحة، لا تلصق فمك.
- لا تنفخ فيه، ولا تضرب عليه.
- اضبط الصوت قبل الأذان إن أمكن.
- إن انقطع، أكمل بصوتك بلا ارتباك.

## ١٢. قائمة التدقيق النهائية

### أولاً: الفقه والمذهب

- [ ] هل سألت عن المذهب قبل الكتابة؟
- [ ] هل الخطبة مبنية على مذهب واحد أو على التقاطع الاحتياطي بوضوح؟
- [ ] هل استوفت الأركان المطلوبة عند المذهب المختار؟
- [ ] هل الجلوس بين الخطبتين واضح؟
- [ ] هل اللغة مناسبة لحكم المذهب؟
- [ ] هل تجنّبت الجزم في المسائل الخلافية؟
- [ ] هل نبّهت أن النص ليس فتوى؟

### ثانياً: المراجع

- [ ] كل آية لها سورة وآية.
- [ ] كل حديث له مصدر ورقم وحكم.
- [ ] كل أثر/قول له كتاب وصفحة إن أمكن.
- [ ] كل بيت شعر له شاعر وديوان (أو «ينسب إلى»).
- [ ] لا يوجد نص «من الذاكرة».
- [ ] سجل المراجع مرفق.
- [ ] الأحاديث الضعيفة حُذفت أو وُسمت.
- [ ] لا توجد نسبة إلى عالم بلا مصدر.

### ثالثاً: البناء والجمهور

- [ ] رسالة واحدة واضحة.
- [ ] افتتاح يشدّ في أول دقيقة.
- [ ] عرض من ثلاث حركات: تشخيص/تأصيل/تطبيق.
- [ ] خاتمة موجزة بلا ذيل.
- [ ] الأولى أطول من الثانية.
- [ ] الطول ١٥–٢٠ دقيقة.
- [ ] اللغة مناسبة للجمهور.
- [ ] لا استطراد ولا حشو.

### رابعاً: اللغة والأسلوب

- [ ] خلا النص من `قام بـ` و`تم من قبل` و`من خلال` و`على صعيد` و`بالنسبة لـ`.
- [ ] الجمل فعلية حيث أمكن.
- [ ] لا سجع متكلف.
- [ ] لا غريب ولا عامية متكلفة.
- [ ] الترقيم سليم.
- [ ] النص مقروء بصوت مسموع بلا تعثر.

### خامساً: الحساسية

- [ ] لا تكفير ولا تفسيق.
- [ ] لا سبّ ولا تجريح.
- [ ] لا أسماء أشخاص في وقائع مشينة.
- [ ] لا تحريض سياسي.
- [ ] لا وصف فجّ للمعاصي.
- [ ] لا سخرية من الناس.
- [ ] روعي محيط المسجد وجمهوره.

### سادساً: الشعر

- [ ] أذن المستخدم.
- [ ] العدد ١–٣.
- [ ] النسبة متحققة.
- [ ] لا يزاحم الدليل.
- [ ] لا يكسر الوزن ولا يحرف المعنى.

| خطبة مليئة بالاقتباسات بلا مصادر | تكديس مراجع | احذف غير المتحقق، وأبقِ ٢–٣ أدلة محورية |
| خطبة طويلة مملة | استطراد وحشو | رسالة واحدة، ١٥–٢٠ دقيقة |
| خطبة كلها ترهيب | فقدان التوازن | بشّر، واذكر الرحمة، واختم بالرجاء |
| خطبة كلها قصص | غياب التأصيل | أضف آية/حديثاً محورياً |
| خطبة تخص شخصاً | تجريح | عمّم ولا تخصّ |
| خطبة لا تناسب المذهب | خلط الأقوال | ارجع إلى جدول المذهب |
| خطبة فيها حديث ضعيف | تساهل في التخريج | احذفه أو اذكره بصفته |
| خطبة فيها بيت شعر بلا نسبة | تساهل في العزو | تحقق أو احذف |
| خطبة تُقرأ قراءة رتيبة | إهمال الإلقاء | تدرّب، نوّع الصوت، ضع فواصل |
| خطبة تبدأ باعتذار طويل | ضعف الافتتاح | ابدأ بالموضوع أو بسؤال |
| خطبة تكرر «إن الله يقول» بلا آية | غموض المرجع | أثبت الآية كاملة |
| خطبة تخلط الفصحى والعامية | اضطراب المستوى | لغة وسطى واحدة |

## ١٥. أوامر التشغيل

| إذا قال المستخدم... | فافعل |
| :--- | :--- |
| «اكتب خطبة جمعة» | اسأل الأسئلة الخمسة، ثم املأ بطاقة الخطبة، ثم اكتب |
| «اكتب خطبة عن...» | اسأل المذهب والجمهور والمدة، ثم اكتب |
| «راجع خطبتي» | شخّص: المذهب، المراجع، البناء، اللغة، الحساسية، الشعر |
| «صحّح المراجع» | تحقق من كل آية/حديث/أثر/بيت، وأعد سجل المراجع |
| «اختصر الخطبة» | احتفظ برسالة واحدة ودليل واحد وتطبيق واحد |
| «أضف شاهداً» | تحقق أولاً، ثم أضف |
| «أضف شعراً» | اسأل الإذن، ثم تحقق من النسبة |
| «ما حكم...؟» | لا تفتِ؛ اعرض أقوال المذاهب بالمصادر، وأحل إلى الجهة المختصة |
| «اكتب خطبة عيد» | طبّق عقد العيد (خطبة بعد الصلاة، تكبيرات، بلا أذان) واسأل عن المذهب |
| «ترجم خطبة» | استدعِ `arabic-tarjama-skill` + `arabic-writing-skill` |

## ١٦. خلاصة جامعة

- **اسأل عن المذهب** قبل أن تكتب.
- **رسالة واحدة**، وجمهور واحد، ووقت واحد.
- **المرجع أولاً**، ثم الصياغة.
- **لا تختلق** آية ولا حديثاً ولا نسبة.
- **لا تفتِ**؛ اعرض واذكر الخلاف.
- **لا تُقحم الشعر** بلا إذن، ولا تنسبه بلا تحقق.
- **لا تُغضب** أحداً؛ المنبر للرحمة والبناء.
- **اقرأ بصوت مسموع**، وتوقّف عند الذروة.
